# 🚀 Sistema de Gestão de Vendas

> Sistema web full stack desenvolvido para solucionar uma **necessidade real de gerenciamento de vendas**, transformando um processo manual em uma aplicação organizada e automatizada.

### 💡 O que o projeto faz

* 👥 Gerenciamento de clientes
* 📦 Cadastro de produtos
* 🎁 Criação e gerenciamento de kits
* 💰 Controle de vendas
* 📅 Cálculo automático de vencimentos
* 🔴 Identificação de vendas atrasadas
* 🔎 Busca e filtros
* ✏️ Edição e exclusão de registros
* 📊 Dashboard

### 🛠️ Tecnologias

**Java • Spring Boot • Spring Data JPA • MySQL • JavaScript • HTML • CSS • REST API • Git**

### 🏗️ Arquitetura

```text
Frontend
   ↓
REST API
   ↓
Spring Boot
   ↓
JPA / Hibernate
   ↓
MySQL
```

### 🎯 Objetivo

Projeto desenvolvido para **estudo, portfólio e aplicação prática**, colocando em prática conceitos de:

* Desenvolvimento de APIs REST
* CRUD
* Banco de dados relacional
* Integração Frontend + Backend
* Persistência com JPA/Hibernate
* Regras de negócio
* Git e GitHub
